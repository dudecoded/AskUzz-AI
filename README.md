# 🤖 AskUzz AI

AskUzz AI is a simple AI chatbot built with React and the Gemini API.

The project was created as a frontend assignment to understand how a React application can communicate with an AI API, manage chat messages, and display responses dynamically.

## 🚀 Live Demo

https://askuzz-ai.vercel.app/

## 📂 GitHub Repository
https://github.com/dudecoded/AskUzz-AI


---

## ✨ Features

- 💬 Chat with an AI
- 🤖 Gemini API integration
- ⚡ Fast and responsive React interface
- 📩 Send messages using the button or Enter key
- ⏳ Loading state while AI is generating a response
- ⚠️ Basic error handling
- 🗨️ Displays user and AI messages separately
- 🔐 API key stored using environment variables

---

## 🛠️ Tech Stack

- **React** – Frontend UI
- **Vite** – Development and build tool
- **Axios** – API requests
- **Gemini API** – AI-generated responses
- **JavaScript** – Application logic
- **CSS** – Styling
